# 轻剪 AI 3.0

Python + Streamlit + FFmpeg 的中文手机端视频剪辑工具，保留原有手动剪辑。

**默认明确标注为规则分析模式，不是语义内容理解。** 3.0 会实际测量画面运动、人物区域运动、清晰度、曝光及相似程度，不随机选段，也不只按上传顺序全部拼接。它仍不能理解投篮/进球/旅行地点/食物种类/故事含义，也不能判断一段画面是否真正“有意义”或“美观”。

## 双模式自动剪辑

1. 上传 MP4 / MOV，切换“自动选段”，选择“运动精彩集锦”或“日常 Vlog”。
2. 调整每段最多保留 2–10 秒、目标 15 / 30 / 60 秒；可调整清晰度阈值、开关重复过滤。
3. 可上传背景音乐：检测前 60 秒能量起音点，在候选时长允许时安排切点，并将同一首音乐混入成片；原声、音乐音量可分别调整。
4. 点击“分析素材并生成候选”查看测量依据，或直接“生成我的视频”。
5. 每个自动片段可以修改开始/结束时间或取消保留；重新生成后预览、下载 MP4。手动改动可能改变总时长和音乐对齐。
6. 支持 9:16（720×1280）、16:9（1280×720）。原有“手动剪辑”保留素材排序和逐段裁剪，不依赖自动分析。

### 实际分析方法

- **运动模式**：2 fps 灰度采样，Farneback 光流减去全画面中位位移，减弱相机平移干扰；使用 OpenCV 内置的预训练 HOG/SVM 行人检测器测量人物区域光流，结合清晰度、曝光评分。长时间静止、低细节/模糊或极端曝光片段不通过默认阈值。优先输出高分动作片段。
- **Vlog 模式**：优先清晰度、曝光和适当画面变化；先选高质量候选池，再按上传素材顺序和素材内时间排序。上传顺序不代表拍摄日期，当前不读取 EXIF 拍摄时间。
- **重复过滤**：代表帧 DCT 感知哈希与 8×8 亮度缩略图双重比较，减少近似重复；这是图像相似度，不是语义去重。固定机位的不同动作可能误判，可关闭去重。
- **质量指标**：去除采样补边后测量 Laplacian 方差及亮度。柔焦、低纹理画面可能被误当模糊，可调低阈值或手动剪辑；并不等同于美学评分。
- **人物检测限制**：内置模型不额外下载，检测站立行人的能力有限，远景、遮挡、运动姿态可能漏检。人物区域光流不是姿态估计或运动事件识别；相机旋转/变焦也可能被算作动作。
- **镜头与声音**：根据采样帧明显变化分镜；保留明显静音检测，Vlog 评分作轻量参考。运动模式不会因背景静音而否定动作。2 fps 采样可能漏掉极短动作/切镜。
- **音乐卡点**：8 kHz 单声道、10 ms 能量变化窗口检测起音点，切点仅在已有候选范围内调整。复杂节奏、弱拍、铺底音乐可能检测失败；无起音点时正常选段，不伪造节拍。不保证所有切点都卡拍，最终还受 30 fps 帧量化和手动调整影响。

未通过质量/动作阈值或被去重后，可用素材可能不足目标时长：页面会说明实际秒数，不复制素材、回填低质量片段或补帧凑时长。没有候选时给出调低阈值或使用手动剪辑的提示。

## 字幕与配乐（保留 2.0 功能）

先生成基础成片，再展开“字幕与背景音乐”并勾选启用：

- 可选语音识别：选择中文或 English，生成相对于**当前成片**的 SRT。使用开源 faster-whisper、多语言 Whisper tiny、CPU int8、2 线程，无需 GPU、付费 API 或密钥。
- SRT 文本框支持预览和修改时间、文字；也可直接粘贴手写 SRT。校验时间范围、顺序、重叠和内容长度，可下载 SRT。
- 上传 MP3 / WAV / M4A 背景音乐（最多 20 MB），调整原声和配乐音量。音乐过短自动循环，过长裁至成片长度；混音限幅避免削波。
- “烧录字幕并合成配乐”生成带字幕的 MP4，单独预览并下载。修改字幕/音量/音乐会使旧合成结果失效。始终保留基础成片的下载入口。

SRT 示例：

```srt
1
00:00:00,000 --> 00:00:01,500
你好，Hello!
```

Whisper tiny 可能误识别或在静音中产生幻觉，不保证字幕准确，需人工校对。不提供翻译或逐词卡拉 OK 字幕。基础成片的静音填充不等同于识别到了语音。

## 安装与启动

基础功能已在 Python 3.12.14 和 3.14.8 验证；需要 Python 3.11+、FFmpeg / ffprobe，FFmpeg 包含 libx264、AAC、libass；中文烧录需要 Noto CJK 字体。

```bash
# Ubuntu / Debian；系统已提供时无需重复安装
sudo apt-get update
sudo apt-get install -y ffmpeg fonts-noto-cjk
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m streamlit run app.py
```

### 启用可选语音识别

基础部署不安装语音识别依赖，避免增加免费实例的内存和下载负担；此时页面禁用识别按钮，手写字幕、烧录、音乐和自动选段仍可用。

```bash
python -m pip install -r requirements-asr.txt
```

首次使用需联网从 Hugging Face 下载 `Systran/faster-whisper-tiny`，并可能访问模型文件 CDN。模型默认缓存到系统临时目录的 `vlog-whisper-models`；可用非秘密环境变量 `VLOG_MODEL_CACHE` 指定可写缓存目录。可将 `VLOG_WHISPER_MODEL` 设置为已下载、可供 CTranslate2 使用的本地模型目录，以避免在线下载。模型缓存有意复用，不保存用户音频。

每次识别在独立子进程中执行，退出后释放模型内存；最多 120 秒成片、5 分钟硬超时。临时音频随任务清理。模型下载/CPU 推理仍可能超出免费平台资源；**不保证 Community Cloud 的任意免费实例都能承载 Whisper**。没有可用模型时会显示中文错误，不会伪造识别结果。素材在应用服务器处理，不发送到付费识别服务。

## Streamlit Community Cloud

1. 仓库选择 `YanmeiHu/my-vlog-editor`，分支选择包含 3.0 提交的分支（合并后可选 `main`），入口 **`app.py`**，不要选择 `hello.py`。
2. Advanced settings 可选择 **Python 3.12**；使用 **Python 3.14** 时本次依赖组合也提供兼容 wheel。基础功能不需要 Secrets。
3. 根目录 `requirements.txt` 安装固定版本 Streamlit、NumPy 和 headless OpenCV（无需 GUI/libGL）；`packages.txt` 安装系统 FFmpeg 和中文字体，无需自定义启动脚本。
4. 若要在线识别，在部署分支的根目录 `requirements.txt` 增加 `faster-whisper==1.2.1` 后重新部署，并保证模型下载网络可用。**不要把 `requirements-asr.txt` 再反向包含进 requirements.txt**，它已包含基础依赖，会造成递归。
5. 用短视频验证自动选段、两种比例、手动剪辑、字幕和下载；启用 ASR 后还需用真实中文和英文语音验收。模型下载与资源问题请查应用日志。

上传默认单个 **50 MB**、合计 **100 MB**、最多 **12 个素材**。总大小校验发生在上传之后，不能阻止上传阶段的全部内存占用。自动分析总素材时长最多 10 分钟，手动成片最多 10 分钟；自动成片最多 60 秒。字幕最多 500 条，每条 2000 字符，文本总计 100000 字符。

每个应用进程同时只允许一个分析/编码/识别/合成重任务，忙时提示稍后重试，不是分布式任务队列。视频编码由 FFmpeg 顺序处理；视觉分析通过临时灰度文件逐帧读取，Python 仅保留相邻两帧及小型测量数据，不把整段视频帧载入内存。256×256、2 fps、10 分钟的灰度中间文件约 75 MiB，任务结束删除。HOG 检测/光流会增加 CPU 时间；对低资源实例优先使用短素材。输出 H.264 / AAC、30 fps、faststart，按比例补黑边；iPhone HEVC 需要系统解码器，HDR 色调映射尚未实现。

上传、成片及 Streamlit 媒体缓存均占内存，应及时下载并清空。每次输入/编码/识别/合成使用独立临时目录，正常完成和异常回退会清理；进程被强制终止可能遗留临时文件。休眠/重启/重新部署不保留用户素材。不要公开部署敏感素材；长期任务、多用户高并发需要对象存储、鉴权和任务队列。

### 修复 Python 3.14 卡在 Building NumPy

旧组合 `numpy==2.2.6` 没有 CPython 3.14 wheel，而 `opencv-python-headless==4.12.0.88` 在 Python ≥3.9 时要求 NumPy <2.3，导致新解释器尝试源码构建或出现依赖冲突。FFmpeg 是独立的系统依赖，不是本次故障原因。

当前固定 `numpy==2.3.5` 与 `opencv-python-headless==4.13.0.92`：前者提供 `cp314-cp314` Linux wheel，后者提供兼容 CPython 3.14 的 `cp37-abi3` Linux wheel，且允许 NumPy ≥2。`requirements.txt` 使用 pip/uv 均支持的 `--only-binary=:all:`，没有适用 wheel 时立即明确报错，不回退到源码编译。NumPy 要求 Python ≥3.11；Linux wheel 要求 glibc ≥2.28，适用于当前 Community Cloud 的 Debian 环境，不保证 Alpine/musl 或所有平台。

已在全新 Python 3.14.8 环境使用 uv 仅安装 wheel 并运行基础功能全部 44 项测试；3.14.10 的补丁版本没有在本地单独运行，两者使用相同 `cp314` ABI。本次未修改剪辑逻辑、Streamlit 版本或 `packages.txt`，可选语音模型的验证边界不变。

更新网站：将修复 PR 合并到 main，确认 Community Cloud 应用部署 main 的 `app.py`，等待依赖重建；若没有自动更新，在 **Manage app → Reboot app** 重启并查看日志。确认日志安装的是 NumPy 2.3.5 / OpenCV 4.13.0.92，不再出现 Building NumPy。Python 版本由 Community Cloud 的部署设置选择，requirements.txt 不会更改解释器；如需更改版本而设置页面不提供入口，按平台流程重新部署应用并在 Advanced settings 选择版本。

## 测试与验证边界

```bash
python -m pytest -q
python -m pip check
```

- 回归测试保留手动裁剪、真实 15/30/60 秒输出、两种比例、字幕烧录与音乐混音。
- 新增确定性像素测试：清晰/模糊对比、光流与相机平移、静止素材排除、重复素材过滤、先质量选择再时间排序。

- 校验视觉分析成功/失败后的临时文件清理；不以进程启动代替功能测试。
- ASR 子进程接口、超时与清理使用替身测试；可选依赖实际安装和导入成功。**本次复查模型仓库仍返回代理 403，真实中文/英文模型推理未验证，不应称为可用的线上语音识别服务。**
- 真实人物运动场景下 HOG 检测准确率、复杂音乐卡点效果、3.0 的 Community Cloud 发布及 iPhone / iPad 真机体验仍待验收。
